## 进阶阅读清单

以下是进一步学习时应取得的资料，**不作为本次已核验全文的引用**：

- GIIGNL《LNG Custody Transfer Handbook》：重点阅读计量、采样、密度、热值、能量计算和不确定度；本次官网内容未能可靠提取，版次及全文待核验。
- IEA《Gas Market Report》系列：学习短中期全球平衡与情景预测；注意报告期、情景假设及预测修订。
- S&P Global Commodity Insights 的 Platts LNG 方法论：核对 JKM 评估地点、窗口、规格及方法变更；购买指数挂钩货之前应取得适用版本及合法数据权限。
- IMO IGC Code 与 SIGTTO 的 LNG 船岸安全资料：由专业团队指导学习，不把交易培训当作现场操作培训。
- ICC UCP 600、ISBP 及银行业务要求：学习跟单信用证和单据审核；需明确适用规则及版本。
- 所选接收站及管网最新服务规则、政府定价文件、海关与税务政策：必须取得适用于本次业务的文件，不能由行业文章代替。

不转载付费报告、标准或商业合同全文。本站的流程清单和练习是原创教学归纳，不代表上述机构背书。

## 常见英文术语

| 缩写或词语 | 中文含义 | 阅读时注意 |
| --- | --- | --- |
| LNG | 液化天然气 | 液体体积与气态标准体积不同 |
| MMBtu | 百万英热单位 | 不是一千 Btu，注意英热单位定义 |
| HHV / GCV | 高位热值 | 与低位热值不要混用 |
| LHV / NCV | 低位热值 | 按合同选择基准 |
| JKM | Japan Korea Marker | 分清现货评估与衍生品 |
| TTF | Title Transfer Facility | 荷兰天然气虚拟交易点 |
| HH | Henry Hub | 美国天然气枢纽，不是 LNG 到岸价 |
| JCC | Japan Crude Cocktail | 日本原油进口价格相关基准，不能与 Brent 混用 |
| SPA | Sale and Purchase Agreement | 买卖协议 |
| MSPA | Master Sale and Purchase Agreement | 主买卖协议，通常配合单笔确认 |
| ACQ | Annual Contract Quantity | 年合同量，不代表每月均匀交付 |
| ADP | Annual Delivery Programme | 年度交付计划，变更权按合同 |
| FOB | Free On Board | 具体交接点及例外按合同 |
| DES | Delivered Ex Ship | LNG 市场常用表述，并非 Incoterms 2020 术语 |
| ETA | Estimated Time of Arrival | 预计抵港时间，注明时区 |
| NOR | Notice of Readiness | 准备就绪通知，有效性影响装卸时间计算 |
| Laytime | 允许装卸时间 | 起算及除外事项需查合同 |
| Demurrage | 滞期费 | 并非所有延误都能索赔 |
| BOG | Boil-off Gas | 蒸发气，处理与结算方式按实际系统及合同 |
| Heel | 余液 | 可能用于冷舱，货权和数量处理需明确 |
| FID | Final Investment Decision | 最终投资决定，不等于投产 |
| Netback | 净回值 | 扣除指定交付链成本后的可比价值 |
| Basis | 基差 | 要明确两个地点、指数或期间 |
| MtM | Mark-to-Market | 按市价估值，不等于已实现现金 |
| LC | Letter of Credit | 信用证，银行通常按单据而非货物审查 |
| KYC | Know Your Customer | 了解客户，包含身份与相关风险核查 |

## 如何保持资料不过时

为每份业务资料记录发布机构、标题、发布日期、生效日期、版本、适用地区及核查日期。遇到价格指数方法变更、税费调整、设施规则变化或制裁更新，应触发重新审阅，而不是等待年度更新。

交易所规则页面可能随时更新，真实交易前应归档当时适用的合约规格。历史贸易数据与市场周报应保留统计期，不覆盖成没有日期的“当前事实”。
