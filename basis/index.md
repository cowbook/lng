# 从行业新手到国际 LNG 交易员

作为国际 LNG 贸易从业者，目标不只是判断气价涨跌，而是把海外供应变成国内可交付、可收款、风险可控的能源产品。交易员必须同时看懂货、船、接收站、合同、资金和下游需求。

本手册按“船货 LNG 从询价到回款”的工作顺序组织。适合贸易助理、市场分析师、采购及销售人员入门；学习进度应以能否完成工作成果衡量，而非仅以阅读时间衡量。

## 学习路线

| 阶段 | 核心问题 | 必须掌握 | 建议交付成果 |
| --- | --- | --- | --- |
| 1. 认识货物 | 买卖的是吨、体积还是能量？ | LNG 物性、组分、热值、质量规格、计量基准 | 一份带单位及假设的货量换算表 |
| 2. 认识市场 | 中国为何需要这船气？ | 全球供需、季节性、长协与现货、国内替代气源 | 一页中国与亚欧市场周报 |
| 3. 算清价格 | 什么价格买入才有利润？ | JKM、TTF、Henry Hub、油价挂钩、到岸与到用户成本 | 一张分清含税与不含税的进口利润表 |
| 4. 审阅合同 | 什么情况下必须接货、付款或赔偿？ | SPA、主协议与确认书、数量弹性、交付条款、信用支持 | 交易条款清单与风险批注 |
| 5. 执行船货 | 货能否按期卸下并送给客户？ | 船期、船岸兼容、计量、单证、接收站及管输安排 | 一份装港到回款的执行时间表 |
| 6. 打通中国交付 | 有进口货源是否等于可以在国内销售？ | 进口合规、设施准入、通关、税费、管输及槽批销售 | 国内交付链核查清单 |
| 7. 管理风险 | 看对行情为什么仍可能亏钱？ | 基差、汇率、信用、流动性、操作风险与套保 | 一份敞口台账和压力测试 |
| 8. 模拟交易 | 能否说清买入依据和最坏结果？ | 询报价、审批、执行、损益归因、复盘 | 一套可以交给风控审阅的模拟交易档案 |

- 使用 [市场信息](/market/) 跟踪行情；核对报价的时间、来源、交付月份及是否为代理数据。公开图表不能替代可成交报价。

## 交易员的工作边界

交易员负责提出交易逻辑、组织商业条件并管理授权范围内的敞口；法律、合规、信用、财税、船务和接收站团队分别把关专业事项。完成学习不等于取得进口、金融衍生品交易或设施使用资格。

尤其不要混淆以下概念：

| 看似相同 | 实际区别 |
| --- | --- |
| LNG 到岸价格与国内销售价格 | 计价单位、税口径、热值基准、交付地点、账期都可能不同 |
| 有接收站能力与有可用窗口 | 年接收能力不等于指定日期的泊位、储罐、气化和外输能力 |
| 基准价格与实际报价 | 基准有定义好的时间及规格，实船可能存在溢价、折价和信用条件 |
| 账面盈利与现金充足 | 保证金、预付款、税款和账期可能先消耗现金 |
| 方向判断正确与套保有效 | 地区、月份、数量、指数和币种不匹配会留下风险 |

## 怎样使用权威资料

优先级是：监管部门原文与现行规则、合同及设施规则、指数方法论和交易所合约规格、国际行业组织报告，最后才是媒体解读。行业报告适合理解结构，不替代法律意见或实时成交数据。

本手册新增专题采用原创归纳和教学练习，不复制付费报告或合同全文。各专题列出来源与使用范围；政策、税费、制裁、合同规格和市场数据均应在成交前重新核验。旧有页面的统计年份按原文保留。

## 毕业练习

模拟为中国沿海客户采购一船 LNG：说明需求与替代气源，统一能量和税费口径，比较 FOB 与到岸报价，确认接收站窗口和下游去向，完成条款审阅、信用审批、压力测试及结算复盘。

**通过标准：** 每个数字可以追溯，每个风险有责任人，每个关键交付条件有确认依据；在无法确认窗口、信用或合规条件时，能够明确建议暂不成交。
